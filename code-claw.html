The brief

Code Claw is a desktop coding agent for real developers. It builds, debugs and ships local projects using a free local model, a private model or your own API key, with a full editor, terminal and git built in.

Developers want an AI agent that can do real work across a whole project, but many cannot send their code to a third-party cloud, and per-token bills add up fast on long tasks. The goal was a desktop app that pairs a proper IDE with an agent that acts end to end, runs on the developer's own machine, and lets them choose any model, from a free offline one to the frontier models they already pay for.

Who it serves: Professional developers, freelancers and teams who want AI help on real projects while keeping their code private and their costs under control.

Inside the product

What made it hard

Private by default

Code had to stay on the developer's machine, so the editor, agent and a local model all needed to work fully offline.

Any model, one experience

Free local models, frontier models and open models behave differently. Switching between them had to be a one-click choice per conversation.

An agent you can trust with your repo

An agent that edits and runs code needs guard rails: every change reviewable, every task undoable, and nothing committed by surprise.

Big jobs, not just snippets

Large tasks had to be split up and coordinated without losing track of cost or quality.

What we built

Editor and IDE

A full, self-hosted code editor with file tree, tabs, project-wide search, syntax highlighting for 20+ languages and an integrated terminal. The editor can be hidden for a clean AI workspace.

An agent that acts

Reads, writes and runs code end to end, with Build, Plan and Ask modes, up to three conversations at once, slash commands, @-file mentions and screenshot input so it can see your UI.

Your models, your rules

A free local model through Ollama that runs offline at no cost, bring-your-own keys for Anthropic, Gemini and OpenAI, and open models such as Kimi, DeepSeek and GLM. Switch per conversation.

Git and safety

Full git (status, branches, commit, push, pull and diffs), accept or reject every change file by file, and an automatic snapshot before each task for one-click undo.

Real dev environment

Support for 40+ frameworks, project scaffolding for React, Vue, Next and Laravel, dev servers and builds run in-app, and live cost tracking per session.

God Mode

A team of AI agents on one big task, with roles from CEO down to specialists, a budget and review step for each subtask, and a live task board to watch progress.

How we worked

  1. Start with the IDE

    We built a complete editor and terminal first, so the agent works inside a real development environment rather than a chat window.

  2. Make the model a choice

    A model layer lets developers move between a free local model, their own API keys and open models without changing how they work.

  3. Put safety around the agent

    Snapshots, per-file review and full git came before autonomy, so developers stay in control of every change.

  4. Scale up to teams of agents

    God Mode coordinates several specialist agents on one task, each with its own budget and review step.

Where it landed

Version 0.1.0 is out as a free download for macOS, Windows and Linux: an AI coding agent that works on real projects, runs on the developer's own machine and keeps their code private.
